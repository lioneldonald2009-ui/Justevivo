# JUSTEVIVO — première base du projet

Cette archive contient une première version front-end statique de JUSTEVIVO.

## Contenu
- `index.html` : page d'accueil et maquette du studio
- `styles.css` : identité visuelle responsive
- `app.js` : interactions de démonstration (import local, aperçu, styles, couleur)

## Tester
Ouvrir `index.html` dans un navigateur récent. L'import vidéo utilise une URL locale temporaire dans le navigateur et ne téléverse rien sur un serveur.

## Publier gratuitement avec GitHub Pages
1. Créer un nouveau dépôt GitHub nommé `justevivo`.
2. Décompresser cette archive et envoyer les trois fichiers (`index.html`, `styles.css`, `app.js`) à la racine du dépôt.
3. Dans Settings → Pages, choisir Deploy from a branch, puis `main` et `/root`.
4. Enregistrer et attendre la publication.

## Limites actuelles
Cette version est une maquette front-end fonctionnelle, pas encore un service de sous-titrage IA. La transcription, la traduction, le rendu vidéo, les comptes, le paiement et les publicités nécessitent un backend, des services adaptés et des tests. Aucun paiement n'est collecté dans cette version.
