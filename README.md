# JUSTEVIVO — Frontend GitHub Pages

Ce dépôt contient l'interface web et le studio. Le nouveau système visuel remplace les anciennes feuilles CSS en cascade. Les scripts fonctionnels existants sont conservés afin de maintenir la compatibilité avec l'authentification Supabase et les routes backend actuelles.

Déploiement : remplacer les fichiers du dépôt GitHub Pages par le contenu de ce dossier, en conservant les paramètres GitHub Pages existants.

Ne pas supprimer les pages légales. Ne pas publier de clés secrètes dans ce dépôt.
